# Pull Shark

Awarded for merged pull requests.

## Requirement
A pull request you opened must be **merged**. Closed-without-merge PRs do not count.

## Tiers
| Tier | Merged PRs |
|---|---|
| Bronze | 2 |
| Silver | 16 |
| Gold | 128 |
| Highest | 1024 |

## Notes
- The PR must target a repository GitHub counts as a contribution target.
- Self-merging your own PR in your own repository counts.
- There is a delay between merging and the badge appearing on the profile.
