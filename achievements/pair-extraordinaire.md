# Pair Extraordinaire

Awarded for co-authored commits on a merged pull request.

## Requirement
Include a `Co-authored-by:` trailer in the commit message:

```
Co-authored-by: Name <email@example.com>
```

## Notes
- The email must resolve to a real GitHub account, otherwise GitHub cannot
  attribute the co-author and the badge does not trigger.
- A `noreply` address that is not linked to an account will not work.
- Tiered; higher tiers need more co-authored merged PRs.
